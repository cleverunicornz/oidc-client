# I-000001 — Upstream attribution is preserved

## Invariant

The crate carries forward code from openidconnect-rs under the MIT license.
The MIT LICENSE file — including its copyright line — is preserved in the
repository. The original authors (ramosbugs / David Ramos and contributors)
are credited in the README and/or NOTICE file. License headers in source
files are not removed.

## Basis

MIT requires that the license text and copyright notice be preserved when
code is redistributed. This is a legal obligation, not a courtesy.
